# 软件项目实施（开发）转运维交付标准 - v3

### 一、代码与制品交付（核心）
1. 软件产品 / 构建产物
   - Jar/War/Bundle/dll/ 镜像包 / 软件安装包
2. 源代码（如有）
   - 完整可编译源码（Git 仓库、分支、Tag）
   - 版本说明、Commit 日志、ChangeLog（记录各版本主要变更内容、修复的问题及新特性，便于追踪项目演进和问题定位）
3. 容器 / 云原生制品（如有）
   - Dockerfile、docker-compose.yaml
   - Helm Chart、K8s YAML（Deployment/Service/Ingress/ConfigMap 等）
### 二、环境与配置交付
1. 环境清单
   - 开发 / 测试 / 生产系统配置要求（CPU、内存、硬盘）
   - 开发 / 测试 / 生产环境信息（IP、域名、端口、路径）
2. 配置文件
   - application.yml、bootstrap.yml、.env、properties、appsettings.json、web.config 等
3. 环境依赖版本
   - JDK/Node/Go/.NET、Nginx、Redis、MySQL、MQ、ES、MSSQL、Linux、Windows 等版本要求
### 三、数据库交付（如有）
1. 数据库脚本
   - DDL：建表、索引、约束、初始化语句
   - DML：基础数据字典、枚举数据
   - 增量更新 SQL、回滚 SQL
2. 数据库文档
   - ER 图、数据字典
3.迁移 / 初始化方案
   - 数据初始化顺序、历史数据迁移脚本
### 四、部署与运维手册
1. 部署文档
   - 部署步骤、启动 / 停止 / 重启命令（或操作说明）
   - 端口占用、路径规划、日志路径
2. 配置说明
   - 核心配置项含义
   - 中间件配置：配置文件路径及关键配置项
3. CPU、内存、硬盘监控指标 监控指标达到阈值后触发 Zabbix 预警

|指标|阈值|
|-|-|
|CPU 使用率|> 90% 持续 2m → 警告；> 90% 持续 10m → 严重|
|内存使用率|> 85% → 警告；> 95% → 严重|
|硬盘分区使用率|> 80% → 警告；> 95% → 严重|
|硬盘分区剩余空间|< 10G → 警告；< 5G → 严重|

4. 数据库监控指标 监控指标达到阈值后触发 Zabbix 预警

|指标|阈值|
|-|-|
|数据库连通状态|不可连通 → 严重|
|运行状态|异常停止 → 严重|
|当前连接使用率|>90% → 严重|
|慢查询数量|持续增长 → 警告|
|缓存命中率|<80% → 严重|
|阻塞会话数|>0 持续 1 分钟 → 警告|
|死锁次数|出现即 → 严重|
|表空间使用率|>85% 警告；>95% 严重|

### 五、运行维护类交付物
1. 日志规范
   - 日志路径、格式、级别、切割策略
2. 备份策略
   - 数据库备份、文件备份、备份周期
3. 运维手册
   - 项目需求文档
   - 系统设计文档
   - 业务蓝图
   - 接口文档
   - 测试文档（用户签字）
   - 操作指引（正向及反向流程，详细视频、文档）
   - 对接资料（配置文档等）
4. 培训记录
   - 用户签到记录
   - 培训音、视频（如有）
5. 交付物清单
   - 列出交接内容（文档、手册等），交接双方确认签字
6.故障处理
   - 常见故障：列出常见的故障类型及处理方法。
   - 故障报警：报警方式（邮件、短信、微信等），报警阈值。
   - 故障恢复：故障恢复步骤，回滚策略。

### 六、账号与权限交付
1. 应用账号清单
   - 管理员账号、业务账号、第三方系统账号
2. 权限矩阵
   - 数据库账号、中间件账号、服务器账号、云资源权限
